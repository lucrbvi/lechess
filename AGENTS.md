# Coding rules:
1. Do not write comments unless it's really necessary
2. In Python code, never use two blank lines between classes, methods, or functions; use exactly one blank line
3. Jump spaces inside classes and methods to be readable
4. Always aim at deleting code and simplify the codebase
5. Prefer a few direct functions over many tiny helpers, wrappers, or dynamic abstractions
6. Keep variables short-lived and avoid naming intermediate values unless they make the code easier to read
7. Do not add classes unless they hold real state or remove meaningful complexity
8. Keep CLI options minimal, but every option must have a practical default when possible
9. When optimizing, preserve a simple data flow that can be read from top to bottom
